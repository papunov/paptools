# paptools - Antigravity Skills & Plugin Module

Модул със скилове и инструменти за Antigravity AI.

## Структура

```text
paptools/
├── plugin.json               # Манифест на модула
├── README.md                 # Документация
├── .gitignore                # Git игнорирани файлове
└── skills/                   # Папка със скилове
    └── sample-tool/
        └── SKILL.md          # Шаблон за скил
```

## Как да свържете с GitHub

1. Създайте ново празно репозиторий в GitHub с име `paptools`.
2. В терминала в тази папка изпълнете:

```bash
git init
git add .
git commit -m "Initial commit of paptools plugin"
git branch -M main
git remote add origin https://github.com/ВАШИЯ-ПОТРЕБИТЕЛ/paptools.git
git push -u origin main
```
